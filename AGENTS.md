# Rutony Credits: инструкции агенту

Самостоятельное расширение RutonyChat для финальных титров стрима.
Сборка и работа не требуют соседних проектов.

Прочитайте [README](README.md), [разработку](docs/project/development.md)
и руководства по затронутой области: [архитектура](docs/project/architecture.md),
[проверки](docs/project/quality.md), [установка](docs/manual-test.md),
[поставка и восстановление](docs/project/delivery.md).

- `integration/rutony_credits.cs` — автономный скрипт RutonyChat;
  `src/RutonyCredits/` — сборщик, хранение, HTTP и web-интерфейс.
  Проверки — в `tests/`, безопасный стенд — в `tools/PreviewHost/`.
- Версии и зависимости определяют `global.json`, `Directory.Build.props`
  и `NuGet.Config`. Основная проверка: `./scripts/build.ps1 -Check`.
  Для документации выполните `scripts/check-publication.ps1`;
  для Workshop-пакета — `tests/workshop.tests.ps1`.
- Сохраняйте имена DLL/скрипта, порт 18765, каталог данных
  `LocalAppData/RutonyCredits` и совместимость существующих форматов данных.
- События приходят через публичные делегаты и пассивный Event List RutonyChat.
  У Twitch один raid ingress; не отправляйте init в Event List.
  Donate принимается независимо от исходного сервиса.
- Сброс сохраняет прежние журналы; перезапуск не возобновляет показ.
  Не добавляйте зависимости от других расширений.
- Используйте синтетические данные. Секреты, пользовательские журналы,
  SDK/бинарники RutonyChat и результаты сборки не входят в Git.
  Сохраняйте изменения других авторов и пользовательские данные.
- Документация и сборка должны оставаться внутри клона, без машинных путей
  и личных файлов. Указывайте выполненные проверки и их ограничения:
  синтетические события не подтверждают доставку реальных событий сервисов.
