# Rutony Credits

Версия — **1.0.0**. [Заметки выпуска](docs/releases/1.0.0.md).

Установка без сборки: [Steam Workshop](https://steamcommunity.com/sharedfiles/filedetails/?id=3834547813)
или готовый ZIP из [GitHub Releases](https://github.com/prisioner/rutony-credits/releases).
Распакуйте ZIP в отдельную папку и следуйте [инструкции установки](docs/manual-test.md).
Готовый пакет не требует .NET SDK или Node.js.

Расширение RutonyChat для финальных титров стрима: рейды Twitch и
VK Video Live, донаты, фолловеры, подписчики и писавшие в чат модераторы. Автономный C#-скрипт
принимает события RutonyChat, библиотека .NET 9 сохраняет журнал,
локальная страница показывает титры в OBS Browser Source.

Доступны ручной запуск и остановка, сброс счётчиков, восстановление журнала,
системные шрифты с автодополнением, размер, цвет, скорость и заголовки,
выбор секций, повтор по кругу и тестовый показ с вымышленными именами. Разделы идут в заданном порядке, внутри
раздела события упорядочены по времени; повторные участия сохраняются.
Донаты принимаются из штатного OnDonate независимо от исходного сервиса;
у каждой новой записи показываются сумма и исходная валюта. По желанию
донаты одного ника в одной валюте суммируются. Форма отмечает несохранённые
изменения. Доступны [автозапуск от сцены и сброс от OBS](docs/obs-automation.md)
после настройки локального подключения. Для модераторов есть список
исключений; известный ведущий исключается автоматически через данные Rutony.

Для разработчиков: соберите пакет из корня самостоятельного клона:

```powershell
./scripts/build.ps1 -Check
```

Пакет появится в `dist/RutonyCredits`. Следуйте
[инструкции установки и ручного прогона](docs/manual-test.md).
В пакете есть **Открыть титры.url**
и **Открыть титры.html** с выбором порта. Скрипт также печатает адрес
управления в окне RutonyChat как явную ссылку «Открыть панель титров».
Пользовательские темы и реальный клик проверяются отдельно.

При работающем скрипте панель доступна по адресу
[127.0.0.1:18765/control](http://127.0.0.1:18765/control), экран OBS —
[127.0.0.1:18765/overlay](http://127.0.0.1:18765/overlay).
Для разработки есть [стенд без аккаунтов](docs/project/development.md).
Фактическая доставка всех событий и поведение установленного OBS требуют
ручного прогона: компиляция обработчиков этого не доказывает.
