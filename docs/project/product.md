# Предмет проекта

Rutony Credits выводит финальные благодарности: рейды Twitch/VK Video Live,
донаты, фолловеры, подписчики и писавшие в чат модераторы. Сборщик работает
внутри RutonyChat; OBS получает прозрачную страницу Browser Source через
локальный HTTP. Отдельный процесс нужен только разработческому стенду.

## Возможности

- Ручной запуск/остановка, один проход или повтор по кругу, тестовый показ.
- Новый период с сохранением прежних журналов; восстановление после рестарта
  без автоматического показа. Пропущенные до включения события не импортируются.
- Системные шрифты с автодополнением, размер, цвет, скорость и заголовки.
- Независимые галочки секций; выключение показа не выключает сбор.
- Рамка и надпись при несохранённых изменениях оформления/настроек OBS.
- Сумма и исходная валюта доната; необязательное суммирование одного ника
  в одной валюте. Журнал и число событий остаются исходными.
- Модераторы по явному признаку роли в сообщении Rutony, без повторов ников,
  с исключением известного ведущего и настраиваемым списком ботов/ников.
- Необязательная локальная интеграция OBS: выбранная Program-сцена запускает
  титры сначала, уход останавливает, Preview не запускает.
- Сброс после наблюдаемой штатной остановки OBS с архивом; защита от
  reconnect/потери связи, предупреждение о непустом периоде при старте.

Разделы: рейды VK, рейды Twitch, донаты, фолловеры, подписчики, модераторы.
Внутри используется время первого события. Повторы сохраняются, кроме
уникальных модераторов и включённого суммирования донатов. Пустые разделы
скрыты. Каждый запуск фиксирует события и настройки; новые события идут
в следующий снимок. По умолчанию один проход, отдельные донаты и все секции.

Донаты принимаются из OnDonate независимо от сервиса: платёжный логин или
другое расширение не нужны. Разные валюты не пересчитываются. Прежние
записи без суммы показываются отдельно без придуманной суммы. Тексты чата
и донатов не сохраняются. Twitch/VK используются через подключения Rutony,
без отдельной авторизации. Полный список молчаливых модераторов недоступен
через подтверждённый интерфейс; текущий режим учитывает писавших.

## Границы подтверждённого

Автоматические проверки используют изолированные данные и fake OBS v5.
Реальные роли, категории событий и виды подписок на настроенных сервисах,
загрузка скрипта и поведение установленного OBS требуют ручной приёмки.
Сброс использует последовательность состояний, а не перехват кнопки OBS;
ограничения и настройка — в [инструкции OBS](../obs-automation.md).

Публикация в Workshop, управление с другого компьютера, импорт прошлой
истории и автоматизация через собственную Twitch/VK авторизацию не входят
в реализацию. [Установка](../manual-test.md) · [Архитектура](architecture.md)
