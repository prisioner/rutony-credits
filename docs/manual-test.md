# Как запустить титры в RutonyChat

Первый просмотр можно сделать без трансляции и донатов. Сначала подключаем
наш скрипт к RutonyChat и смотрим вымышленные титры, затем добавляем их в OBS.
В конце отдельно проверяем настоящие события.

Нужен готовый пакет `dist/RutonyCredits` из этого проекта. Собирать код,
устанавливать SDK и вводить команды для этой инструкции не требуется.

Чтобы открыть панель без ввода адреса, дважды щёлкните **Открыть титры.url**
в готовом пакете. Ярлык можно скопировать на рабочий стол. Он использует
порт 18765. Если порт менялся, откройте **Открыть титры.html**, укажите
свой номер и нажмите **Открыть титры**. Для открытия панели должен
работать скрипт титров.

## Обновление через установщик и восстановление

Вместо ручного копирования в пунктах 3–5 рекомендуется установщик: он
проверяет весь комплект до замены файлов и при ошибке восстанавливает
предыдущую версию. Остановите отдельный стенд и полностью закройте RutonyChat.
Распакуйте **весь** пакет, включая `install.ps1`, `package-contract.ps1` и
`package-manifest.json`. Откройте PowerShell в папке пакета и выполните,
подставив папку установки:

```powershell
./install.ps1 -RutonyDirectory '<папка установленного RutonyChat>'
```

После успешной установки переходите к пункту 6. Копия всех прежних файлов
расширения сохраняется в `scripts/.RutonyCredits-install/<transaction-id>/backup`;
перечень и прежние хэши — в соседнем `snapshot.json`. Настройки, счётчики и
журналы из каталога данных не заменяются.

Если установка прервана или написано **ROLLBACK FAILED**, оставьте RutonyChat
закрытым, устраните причину ошибки (например, блокировку файла) и из **того же
сохранённого полного пакета** выполните:

```powershell
./install.ps1 -RutonyDirectory '<папка установленного RutonyChat>' -Recover
```

После успешного восстановления повторите обычную установку без `-Recover`.
Если восстановление не удалось, сохраните весь каталог transaction и
`active.json`; не удаляйте их ради обхода проверки. Замена нескольких файлов
не является атомарной: после прерывания может потребоваться этот шаг.

## 1. Остановите отдельный тестовый стенд

Стенд — это временная программа, которую разработчик запускал для просмотра
страницы без RutonyChat. Кнопка «Остановить» на странице прекращает только
прокрутку титров: сам стенд продолжает работать и занимает порт.

Если стенд запущен в вашей консоли, нажмите в этой консоли **Ctrl+C**.
Если стенд работает в фоне, завершите именно его процесс через Диспетчер задач.
Закрытие вкладки браузера сервер не останавливает.

**Проверка:** обновите `http://127.0.0.1:18765/control` через **Ctrl+F5**.
Когда стенд остановлен и наш скрипт ещё не включён, страница не открывается.
Это ожидаемо. После включения скрипта тот же адрес снова заработает.

## 2. Полностью закройте RutonyChat

1. Найдите значок RutonyChat рядом с часами Windows. Он может находиться
   под стрелкой скрытых значков.
2. Нажмите на него правой кнопкой и выберите **«Выход»**.
3. Убедитесь, что программа завершилась. Крестик окна может только спрятать
   её в трей. Если сомневаетесь, откройте Диспетчер задач через
   **Ctrl+Shift+Esc** и посмотрите, остался ли процесс RutonyChat.

Дальше обновляем библиотеку, поэтому RutonyChat должен быть закрыт.

## 3. Откройте две папки в Проводнике

**Первая — готовый пакет.** Откройте папку проекта, затем `dist`,
затем `RutonyCredits`. Внутри должны быть:

- `RutonyCredits.dll` и `LICENSE` с текстом лицензии MIT;
- папка `web`;
- `rutony_credits.cs`;
- `rutony_credits.json`;
- `install.ps1`, `package-contract.ps1`, `package-manifest.json` и копия этой инструкции;
- `Открыть титры.url` и `Открыть титры.html`.

**Вторая — установленный RutonyChat.** Найдите RutonyChat в библиотеке Steam.
Откройте его меню управления и пункт просмотра локальных файлов.
В этой папке находятся `RutonyChat.exe` и `RutonyChat.dll`.
Откройте внутри неё папку `scripts`.

Держите оба окна Проводника открытыми: из первого копируем, во второе вставляем.
Если одноимённые файлы нашего расширения уже установлены, перед заменой
сохраните их копии в отдельной папке. Чужие скрипты оставьте на месте.

## 4. Скопируйте библиотеку и страницу

1. Во второй папке, то есть внутри `scripts` установленного RutonyChat,
   откройте папку **`RutonyCredits`**. Если её нет, создайте папку с этим именем.
2. В первом окне выберите **`RutonyCredits.dll`**, **`LICENSE`** и папку **`web`**.
   Для выбора нескольких объектов можно удерживать **Ctrl** и нажать на каждый.
3. Нажмите **Ctrl+C**.
4. Переключитесь во второе окно с открытой папкой `scripts/RutonyCredits`.
5. Нажмите **Ctrl+V**. Если Windows предлагает заменить наши прежние файлы,
   подтвердите замену.

**Проверка:** внутри `scripts/RutonyCredits` лежат DLL, LICENSE и папка `web`.
Внутри `web` есть файлы `control.html`, `overlay.html` и остальные CSS/JS.

## 5. Скопируйте сам скрипт и его параметры

1. Во втором окне вернитесь на один уровень вверх, в папку **`scripts`**.
2. В первом окне выберите **`rutony_credits.cs`** и **`rutony_credits.json`**.
3. Нажмите **Ctrl+C**, переключитесь во второе окно и нажмите **Ctrl+V**.
4. Подтвердите замену этих двух файлов, если они уже были установлены.

В итоге должно получиться так:

```text
папка установленного RutonyChat/
└── scripts/
    ├── rutony_credits.cs
    ├── rutony_credits.json
    └── RutonyCredits/
        ├── RutonyCredits.dll
        ├── LICENSE
        └── web/
            ├── control.html
            ├── overlay.html
            └── остальные CSS и JS
```

Файлы `.cs` и `.json` должны находиться рядом, непосредственно в `scripts`.
В окне выбора скрипта дальше понадобится файл **`.cs`**.

## 6. Включите скрипт в RutonyChat

1. Запустите RutonyChat обычным способом через Steam.
2. Откройте главное меню программы и перейдите в
   **«Удалённое управление» → «Автономные скрипты»**.
   Этот маршрут указан в [ответе разработчика RutonyChat](https://steamcommunity.com/app/524660/discussions/0/4202489789154799439/).
3. Добавьте одну запись для наших титров. Если такая запись уже есть,
   откройте её для редактирования. Название можно задать **«Титры»**.
4. В поле выбора скрипта выберите **`rutony_credits.cs`** из папки `scripts`.
5. Откройте параметры выбранного скрипта. Рядом с выбором файла должна
   появиться кнопка настройки параметров из соседнего JSON-файла.
6. Установите значения:

   | Параметр | Что указать |
   |---|---|
   | Папка пакета / `PackageDirectory` | Оставить пустым |
   | Папка журналов / `DataDirectory` | Оставить пустым |
   | Порт / `Port` | `18765` |

7. Нажмите **«Сохранить»** в окне параметров. В окне «Пресет скрипта»
   оставьте включённой галочку **«Разрешить события оповещений»**.
   Для сбора модераторов оставьте включённой и галочку
   **«Разрешить сообщения от чата»**. Текст сообщений не сохраняется.
   Внизу слева поставьте галочку **«Включено»**, затем нажмите **«ОК»**.
8. Если после сохранения запуск не произошёл, воспользуйтесь кнопкой
   **«Переподключить»** в окне автономных скриптов, если она доступна.
   Затем посмотрите сообщения в окне RutonyChat.

**Проверка:** должно появиться наше сообщение **«Rutony Credits включён»**
с адресами управления и OBS. Сборка скрипта при первом запуске может занять
несколько секунд. При сообщении об ошибке переходите к разделу помощи ниже.
Скрипт выводит ссылки **«Открыть панель титров»** и **«Экран титров для OBS»**.
Передаётся готовая HTML-ссылка, поэтому старая тема default не должна
распознавать голый localhost URL. Проверены пути default/default-v2;
пользовательская тема и открытие браузера из Rutony проверяются вручную.
При скрытых системных сообщениях используйте собственный ярлык пакета.

Названия некоторых кнопок могут отличаться между версиями RutonyChat.
Ориентир — раздел автономных скриптов и наше сообщение об успешном запуске.

## 7. Убедитесь, что сервер теперь работает внутри RutonyChat

1. Откройте в обычном браузере
   [панель титров](http://127.0.0.1:18765/control).
2. Если вкладка уже открыта после старого стенда, нажмите **Ctrl+F5**.
3. Посмотрите на плашку вверху страницы.

**Правильная плашка: «Подключено».**
Надпись «Тестовые данные» в плашке означает, что открыт отдельный
стенд. Закройте его и проверьте запуск скрипта.

Кнопки запуска, остановки и оформления находятся на этой странице.
Пока используется наш скрипт, RutonyChat должен оставаться запущенным.

## 8. Попробуйте титры без стрима

1. На странице управления нажмите **«Тестовый показ»**.
2. В окне предпросмотра появятся вымышленные участники. Текст движется
   снизу вверх, разделы проходят один раз, затем экран пустеет.
3. Нажмите **«Остановить»** во время показа: текст должен исчезнуть.
4. В блоке оформления измените шрифт, размер, скорость или заголовок.
5. Нажмите **«Сохранить оформление»**, затем снова **«Тестовый показ»**.

Изменения оформления применяются к следующему запуску. Тестовые имена
не записываются в список настоящих событий.

## 9. Добавьте титры в OBS

1. Откройте OBS и выберите сцену, на которой хотите проверить титры.
2. В блоке **«Источники»** нажмите **«+»** и выберите **«Браузер» / Browser**.
3. Создайте источник с названием **«Титры»**.
4. В свойствах источника выключите **«Локальный файл»**, если эта опция включена.
5. В поле **URL** вставьте `http://127.0.0.1:18765/overlay`.
6. Укажите ширину **1920** и высоту **1080**.
7. Оставьте выключенными опции отключения источника при скрытии
   и обновления браузера при активации сцены. Описание этих опций есть
   в [официальной справке OBS](https://obsproject.com/kb/browser-source).
8. Сохраните свойства источника. Убедитесь, что рядом с ним включён «глаз»
   и что источник расположен выше фона или видео, которое может его закрыть.
9. Вернитесь в браузер с панелью управления и нажмите **«Тестовый показ»**.

**Проверка:** титры одновременно видны в предпросмотре панели и на сцене OBS.
Между показами источник пустой, его фон прозрачный. Тестовый показ виден
и в OBS: используйте тестовую сцену, если уже ведёте трансляцию.

## 10. Проверьте настоящие события

1. В RutonyChat используйте свои обычные подключения Twitch, VK Video Live
   и DonationAlerts. Расширение использует полученные RutonyChat события.
2. На странице управления нажмите **«Сбросить счётчики»** и подтвердите.
   Предыдущий список перестанет участвовать в новых титрах; старый журнал
   останется на диске.
3. Оставьте RutonyChat со включённым скриптом работать во время стрима.
   Новые события должны увеличивать счётчики в панели.
4. В конце нажмите **«Запустить титры»**. Если событий ещё не было,
   настоящий показ будет пустым — для проверки картинки используйте
   «Тестовый показ» из предыдущего раздела.
5. Проверьте, что повторные участия сохранены отдельными строками,
   а рейды двух площадок разделены.

События до включения скрипта не импортируются. Новое событие, пришедшее
во время уже запущенных титров, попадёт в следующий запуск.
Донаты принимаются из штатного OnDonate RutonyChat независимо от
исходного сервиса. Начало периода ручное. По умолчанию один проход;
галочка повтора включает цикл до нажатия «Остановить».
Проверять донаты платежами специально ради теста не нужно.

## Если что-то не получилось

| Что видно | Что проверить |
|---|---|
| Страница не открывается | Включён ли скрипт, появилось ли «Rutony Credits включён», совпадает ли порт |
| В плашке написано «Тестовые данные» | Остановите отдельный стенд; затем включите скрипт и обновите страницу |
| Ошибка занятого порта | Убедитесь, что стенд остановлен и включена только одна запись нашего скрипта |
| Скрипта нет в списке | Проверьте, что `rutony_credits.cs` лежит непосредственно в `scripts`; полностью перезапустите RutonyChat |
| Нет окна с тремя параметрами | Проверьте, что `rutony_credits.json` лежит рядом с `.cs`, с тем же базовым именем |
| Параметры открылись, но строки «Порт» нет | Обновите `rutony_credits.json` из свежего пакета; в ранней версии поле имело неверный тип и скрывалось. Закройте окно параметров и откройте заново; при необходимости полностью перезапустите RutonyChat |
| «Не удалось запустить» | Сверьте дерево файлов из шага 5, пустые пути и порт; после обновления DLL полностью перезапустите RutonyChat |
| Панель работает, в OBS пусто | Запустите «Тестовый показ», проверьте URL `/overlay`, видимость и положение источника |
| Кнопки перестали работать после перезапуска скрипта | Обновите панель через Ctrl+F5 |
| Не растут реальные счётчики | Нужны новые события при включённом скрипте; сначала проверьте, получает ли их сам RutonyChat |

Если ошибка остаётся, сохраните её текст или снимок окна настроек скрипта
и укажите номер шага. Нативная загрузка и реальные источники относятся
к первому ручному прогону; компиляция скрипта сама по себе их не подтверждает.

## Как выключить титры и где остаются данные

Кнопка **«Остановить»** прекращает текущий показ. Чтобы выключить всё
расширение, отключите его запись в автономных скриптах RutonyChat.
После выгрузки нашего скрипта сервер остановится, а RutonyChat продолжит работу.
Полное закрытие RutonyChat также останавливает расширение.

Журналы и оформление по умолчанию хранятся в пользовательском каталоге
`LocalAppData/RutonyCredits`, отдельно от установленного пакета.
Обновление пакета их не удаляет. Это пользовательские данные: в Git и
Steam Workshop их не публикуют. В журнале только имя, категория, площадка,
технические идентификаторы, время и, для новых донатов, сумма с исходной
валютой. Текст доната не сохраняется. Старые события без суммы остаются
совместимыми; восстановить неизвестную сумму задним числом нельзя.

`settings.json` содержит оформление: `fontFamily` (шрифт), `fontSize`
(размер 16–160 px), `textColor` (`#RRGGBB`), `speed` (10–400 px/с)
и `headings` с заголовками шести разделов, `enabledSections`
с галочками и `loop` с режимом повтора. Меняйте их через панель.
Файл появляется после сохранения; до этого действуют значения по умолчанию.
`current.json` — JSON-строка с ID активного периода,
`sessions/<id>.jsonl` — его события; новый период сохраняет старые журналы.
Не редактируйте эти служебные файлы для сброса счётчиков.

Параметр скрипта `DataDirectory` переопределяет каталог данных;
пустое значение оставляет `LocalAppData/RutonyCredits`. Если выбираете
новую папку, остановите скрипт и заранее скопируйте туда весь прежний
каталог данных. Пустая папка создаст новый период. Два экземпляра не
должны одновременно использовать один каталог.

При ошибке журнала панель блокирует реальные титры. Preview доступен.
Устраните проблему диска и нажмите «Сбросить счётчики»; старый файл останется.

## Для разработчика

Готовый пакет собирается из корня проекта командой `./scripts/build.ps1 -Check`.
Для обновления используйте установщик из полного пакета, как описано ниже.
Он сохраняет все прежние файлы расширения одним комплектом. При обновлении
DLL RutonyChat должен быть полностью закрыт.


## Проверка изменения и остановки пресета

После обновления полностью перезапустите RutonyChat, чтобы загрузилась
новая DLL. В окне автономных скриптов измените название тестового пресета
и сохраните, затем выключите его и нажмите «Переподключить».
Интерфейс должен отвечать, локальная страница выключенного расширения
перестанет открываться. Включите пресет снова на прежнем порту:
страница и сохранённые данные должны быть доступны.
Удаление тестового пресета также проверяется отдельно; файлы данных
ради этого не удаляются. Это ручная проверка конкретной установки,
а не результат автоматического UI-context теста.

## Новые настройки показа

1. В поле шрифта начните вводить название. Список берётся с компьютера
   RutonyChat; выберите вариант мышью либо стрелками и Enter. Escape
   закрывает список, ручной ввод остаётся доступен.
2. Отметьте секции для следующего показа. Выключенная секция продолжает
   собираться; все снятые галочки дают пустой завершённый показ.
3. Для бесконечного повторения включите «Повторять титры по кругу»,
   сохраните и запустите тестовый показ. Для остановки нажмите «Остановить».
4. После сохранения новые параметры применятся к следующему запуску.
   Уже запущенный показ сохраняет прежние данные и оформление.
5. В секции донатов проверьте имя, сумму и валюту у каждой записи.
   Галочка «Суммировать донаты» объединяет один ник и валюту; по умолчанию
   донаты идут отдельно. Старые записи без суммы показывают имя.

При обновлении этой версии замените не только DLL/web, но и
rutony_credits.cs в scripts из того же пакета: именно скрипт передаёт
денежные поля. Используйте установщик либо штатные шаги ручной установки.


После обновления перезагрузите панель через Ctrl+F5. В OBS обновите страницу
Browser Source кнопкой обновления в свойствах источника, чтобы загрузились
новые файлы overlay.js/playback.js/local-font.js. Простого перезапуска RutonyChat
недостаточно для уже открытой страницы OBS.

## Проверка новых настроек, модераторов и OBS

- Измените настройку оформления: появятся рамка и надпись о несохранённых
  изменениях. Верните прежнее значение — надпись исчезнет. После успешного
  сохранения она также исчезает; при ошибке введённое остаётся в форме.
- Включите **«Суммировать донаты»**, сохраните и начните новый показ.
  Донаты с одинаковым ником без учёта регистра и одной валютой займут одну строку
  на месте первого доната, независимо от площадки. Например, Orbit и orbit
  объединяются; остаётся первое написание в хронологическом порядке.
  USD и usd считаются одним кодом валюты; знак $ не подменяется кодом USD.
  Разные валюты и записи без суммы не объединяются.
  Сам журнал и число полученных донатов остаются исходными.
- Модератор Twitch/VK Video Live пишет сообщение в чат — ник появляется
  в отдельной секции **«Модераторы»** один раз. Обычный пользователь не
  должен появиться там. Секция отключается своей галочкой; текст чата
  в журнал не попадает. Twitch/VK используются через подключения Rutony.
- Полный состав молчаливых модераторов пока не подтверждён доступным API.
  В текущем режиме учитываются модераторы, написавшие сообщение.
- Для выбора сцены, автозапуска и сброса следуйте
  [инструкции OBS](obs-automation.md). Приёмка включает Preview/Program,
  уход/возврат, штатный stop, сетевой reconnect и разные порядки перезапуска.

## Исключения модераторов

В блоке оформления есть поле **«Исключения модераторов»**. Введите по
одному нику на строку и сохраните оформление. Можно указать известных
ботов; регистр и @ в начале не важны. Внутренние пробелы и запятые остаются
частью ника. Ограничение — до 50 ников по 200 знаков; для чрезмерно длинного
списка панель предложит сократить ввод. Пустой список никого не исключает.

После сохранения списка новые события этих модераторов не записываются в журнал
и не увеличивают счётчики. Старые записи сохраняются, но пока ник исключён,
не входят в «Всего событий» и не вызывают предупреждение о непустой статистике
при запуске Rutony или трансляции OBS. После снятия исключения старые записи
снова учитываются; события, пропущенные во время исключения, не добавляются
задним числом. Донаты, фолловеры и другие типы событий того же ника принимаются
как прежде. Уже идущий показ заморожен; чтобы увидеть новое правило, запустите
титры снова. Изменения списка помечаются той же рамкой несохранённых настроек.

Проверка: сохраните ник в исключениях, сбросьте счётчики и отправьте от него
сообщение как от модератора. Все счётчики и «Всего событий» должны остаться
нулевыми, в том числе после перезапуска Rutony. Предупреждения о непустом
периоде быть не должно. Уберите ник из исключений и повторите сообщение:
модератор должен появиться в статистике.

Ведущий Twitch определяется по подключённому каналу. Для VK расширение
запрашивает ID/ник владельца один раз для текущего подключения/канала
через уже авторизованный API Rutony;
без нового входа и чтения токенов расширением. При успешном ответе ID
исключает ведущего даже при смене отображаемого ника. Известный ведущий
сохраняется вместе с периодом и используется после перезапуска только для
того же подключённого канала. При неизвестном/другом канале прежний владелец
не исключается. Смена подключения обнаруживается также без новых сообщений,
в течение очередного секундного опроса. Если данные VK
недоступны, добавьте свой ник в ручные исключения. Роль moderator=true сама
по себе не отличает ведущего от обычного модератора.


## Проверка нестандартного системного шрифта

После установки шрифта перезапустите браузер/OBS, чтобы процесс обновил
каталог шрифтов. Выберите точное семейство в панели, сохраните и начните
новый тестовый показ. Проверьте обычные строки и жирные заголовки с
латиницей и кириллицей в preview и Browser Source. Для семейства с одним
начертанием жирный заголовок может синтезироваться браузером. Если точное
локальное начертание недоступно движку, титры используют прежний CSS fallback.
Расширение не устанавливает и не раздаёт font files. Сверяйте также Arial
и неизвестное имя; при неизвестном имени текст должен остаться видимым.

## Восстановление и перегрузка

Если повреждено оформление, поправьте его в панели и нажмите «Сохранить
оформление». Это не требует сбрасывать собранные события. Сброс счётчиков
не исправляет оформление; сохранение оформления не исправляет повреждённый
журнал. Реальный показ разрешается после устранения обеих причин. Исходные
заменённые файлы остаются рядом с суффиксом .recovery-<guid>, старые журналы —
в sessions. Не удаляйте их до проверки восстановления.

При сообщении о заполненной очереди команд дождитесь завершения текущей
обработки и повторите действие. Потери событий отдельно отмечают период
неполным; такой период нельзя показывать как полный без явного сброса.
На копии тестовых данных проверьте Save→restart при плохом settings.json,
Reset при плохом оформлении и сохранность прежнего журнала. Для проверки
канала переключите подключение Rutony: прежний ведущий не должен скрываться
на другом/неизвестном канале. Реальные настройки и журналы для fault-тестов
не повреждайте.

## Получение рейдов Twitch

После обновления установите весь комплект (скрипт, DLL и web) и полностью
перезапустите RutonyChat. Дополнительный вход в Twitch или адрес вручную
не нужны: источник автоматически использует локальный сервер Rutony.
В панели под счётчиками появится строка **«Рейды Twitch: Подключено к Rutony»**.
Если она показывает ожидание или переподключение, проверьте локальный сервер
Rutony; Event List должен получать рейды. Сам оверлей Event List держать
открытым не требуется. PreviewHost такую строку не показывает.

Проверьте настоящий входящий рейд Twitch: счётчик увеличивается один раз,
ник появляется в разделе Twitch следующего показа. Рейды VK должны работать
как прежде. Два одинаковых реальных рейда остаются двумя записями. Настройка
видимости секции титров не отключает сбор. Встроенный тестовый рейд Rutony
может выглядеть для скрипта как реальный; собственный Preview не меняет сбор.

Перезапуск скрипта сохраняет журнал и заново подключает источник. Во время
разрыва связи рейды могут быть пропущены; после восстановления подключение
возобновляется автоматически. Старые рейды, пропущенные прежней версией или
во время отключения, не импортируются из истории автоматически.
