[h1]Credits — Титры[/h1]
Финальные титры стрима для OBS Browser Source. Собирает события RutonyChat и показывает участников по разделам, в порядке поступления событий.

[h2]Возможности[/h2]
[list]
[*]Рейды Twitch и VK Video Live, донаты, фолловеры и подписчики.
[*]Писавшие в чат модераторы без повторов, исключение ведущего и настраиваемый список исключений.
[*]Сумма и валюта рядом с донатером; по желанию — суммирование одного ника и валюты без учёта регистра.
[*]Выбор секций, системного шрифта, размера, цвета, скорости и заголовков.
[*]Однократный показ или прокрутка по кругу; тестовый просмотр на вымышленных данных.
[*]Автозапуск от сцены OBS и отложенный сброс после остановки трансляции при настроенном OBS WebSocket.
[*]Журнал событий и сохранение настроек между запусками.
[/list]

[h2]Как начать[/h2]
Подпишитесь, дождитесь загрузки Steam и перезапустите RutonyChat. В «Удалённое управление → Автономные скрипты» добавьте один пресет rutony_credits.cs. Оставьте папки пустыми, разрешите события оповещений и сообщения чата, включите скрипт. Для модераторов нужны сообщения чата.

Панель управления:
[code]http://127.0.0.1:18765/control[/code]
Адрес для OBS Browser Source:
[code]http://127.0.0.1:18765/overlay[/code]
Адреса работают на компьютере с запущенным скриптом. OBS WebSocket настраивается отдельно, если нужна автоматизация.

[h2]Требования[/h2]
Windows, RutonyChat с совместимым .NET 9 runtime и подключёнными источниками событий. Для Twitch-рейдов нужен работающий локальный сервер RutonyChat. OBS используется для показа титров. .NET SDK и Node.js для готового пакета не нужны.

Настройки и журналы хранятся отдельно от Workshop. При переходе с ручной установки отключите прежний пресет, чтобы не запускать две копии. После обновления DLL перезапустите RutonyChat.
